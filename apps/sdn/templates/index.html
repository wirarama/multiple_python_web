Visualisasi Cluster ?

Ukuran lingkaran server — kapasitas; warna — tingkat utilisasi (hijau=aman, kuning=sibuk, merah=overload) untuk hasil algoritma terpilih. Seret (drag & drop) server maupun klien untuk mengubah posisinya — posisi baru ikut tersimpan pada export/import konfigurasi dan mempengaruhi latensi jaringan (sehingga hasil load balancing ikut menyesuaikan).

Saran Auto-Scaling Server ?

Server dengan utilisasi tinggi pada hasil algoritma terpilih diberi saran scale up: Scale Up (Vertical) — naikkan kapasitas server — saat sibuk (≥80%) namun belum ada request ditolak; Scale Out (Horizontal) — tambah instance server — saat sudah overload (≥100%, request mulai ditolak).

Log Klien & Server yang Melayani ?

Untuk algoritma terpilih pada tabel hasil: jumlah request & total beban tiap klien, serta server mana saja yang menanganinya.

Jenis Intrusion & Potensi

Centang jenis intrusion yang ingin disimulasikan & dideteksi, lalu atur potensi/intensitasnya (0-100%). Traffic dari client penyerang dibangkitkan sesuai jenis & potensi yang dicentang (dibobot); bila tidak ada yang dicentang, seluruh traffic (termasuk dari client penyerang) dianggap normal.

Perbandingan Variabel: Normal vs Serangan

Kurva menunjukkan sebaran nilai fitur (diurutkan naik, sumbu-x = persentil sampel) untuk membandingkan traffic normal dengan traffic tiap jenis intrusion yang dicentang — makin jauh & makin curam jarak kedua kurva, makin kuat variabel tsb membedakan serangan dari traffic normal (sesuai fitur kunci per jenis intrusion).
